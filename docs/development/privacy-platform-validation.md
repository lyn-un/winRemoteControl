# 隐私控制平台验证记录

本页用于记录 Windows 隐私屏与显示器电源策略的真实设备验证。自动化测试只能证明状态、协议和适配器调用边界，不能证明特定 DWM、GPU 驱动或显示器组合的实际行为。

## 当前发布状态

| 功能 | 代码状态 | 生产能力 | 人工验证 |
| --- | --- | --- | --- |
| 纯黑隐私屏 | 已实现 | 发布 | 待双机、多显示器验证 |
| `Ctrl+Alt+Shift+P` 物理恢复 | 已实现 | 隐私屏期间启用 | 待真实键盘与远程注入对照验证 |

| 关闭显示器 | 已实现 | 默认隐藏 | 待平台矩阵验证后决定是否开放 |

## 隐私屏检查表

- [ ] 本地每个显示器均为纯黑，控制端 DXGI 画面不包含遮罩。
- [ ] 遮罩不抢焦点、不进入 Alt+Tab、不阻止远程输入。
- [ ] 物理快捷键能恢复，远程注入同一快捷键不能恢复。
- [ ] 100%、125%、150% DPI 与分辨率切换无残留窗口。
- [ ] 显示器热插拔、旋转和主屏切换后仍为全有或全无。
- [ ] 记录 Windows 版本、GPU、驱动、DWM 状态与结果。

## DisplayOff 检查表

- [ ] 关闭后至少 30 秒持续收到 DXGI 帧。
- [ ] 记录鼠标、键盘和远程输入是否会唤醒显示器。
- [ ] 分别验证笔记本内屏、单外屏和多显示器。
- [ ] 验证电源计划与 Modern Standby 差异。
- [ ] 正常断开、恢复超时和被控端主动停止均恢复显示。
- [ ] 验证失败时保持 `bAdvertiseDisplayOff=false`。

在以上 DisplayOff 项目完成前，不得在生产组合根开启 rollout policy。
